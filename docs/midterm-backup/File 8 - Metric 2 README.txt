METRIC 2 (ISSUE RECALL) BACKUP

Files
File 8 - Metric 2 summary.csv has the headline numbers.
File 8 - Metric 2 scoring sheet - mock.csv and File 8 - Metric 2 scoring sheet - real.csv list every K and B reference pair, the reviewer's decision, the tool finding that matched, and the result. The real sheet holds codes and tags only, with no interview text.
The lookup from the tool's labels to V1 codes is File 4.

Method
The AI drafted the reference pairs (mock pairs start from the team's answer key). One team member then checked every pair against its transcript, re-read each transcript in full, and added anything missed. We did this after seeing the tool's output, so the lists are not blind or independent.

Scoring
A pair is a strict hit when a finding carries the matching label. For each strict miss, the reviewer judged whether another finding covered the same issue. Only Include pairs count, and Kofi K05 (control) is left out.

Results (target 70%)
Mock: 17 of 29 (59%) strict, 21 of 29 (72%) with same-issue findings.
Real: 12 of 24 (50%) strict, 14 of 24 (58%) with same-issue findings.
